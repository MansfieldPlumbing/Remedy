# Remedy Build Documentation

This document describes the canonical local build system for the Remedy project.

## Prerequisites

- **MSVC**: Visual Studio C++ Compiler supporting C++20 (`cl.exe`).
- **CMake**: Version 3.20 or later (`cmake.exe`).
- **CTest**: Test driver bundled with CMake (`ctest.exe`).
- **PowerShell**: PowerShell 5.1 or PowerShell Core.

## Environment & Build Setup

Environment variables for the build toolchain (compiler, headers, libraries, and runtime DLL paths) are configured automatically by `build.ps1`.

All build artifacts generated by CMake, MSBuild/NMake, and test runs are placed strictly under:

```text
S:\Remedy\build
```

## Canonical Local Build Command

To perform a clean build and run all active native tests, execute the canonical driver command:

```powershell
.\build.ps1 -Clean -Test
```

### Options

- `-Clean`: Removes the `S:\Remedy\build` directory before configuring and building.
- `-Test`: Executes active native tests via CTest after compilation.

## Fail-Fast Principles

`build.ps1` operates as a strict fail-fast driver:
- Every external command (`cmake`, `ctest`) is followed immediately by inspecting `$LASTEXITCODE`.
- If configure or build fails, execution halts immediately with a non-zero exit code.
- CTest is never invoked following a failed build step.
